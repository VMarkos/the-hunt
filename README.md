# The Hunt

A game about hunting, raccoons, birds and Machine Learning.

## What is this?

This is a game we will be developing together, among other projects, aiming to explore:

* game design principles;
* Godot as a game engine, and;
* machine learning architectures.

## Okay, where is the game?

Well, typically, we will add a new [release](https://docs.github.com/en/repositories/releasing-projects-on-github/about-releases) (check on the right of the screen),
under the title **Releases** every week or, in general, whenever we have something new to show. In each release you will find all the source code of the project,
so you can build on your own pace at home and also a ZIP file containing a Godot export, which you can import into your own instance of Godot.

So, stay tuned...
